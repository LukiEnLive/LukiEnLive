## 🧑‍💻 About Me

I'm a software engineer interested in building reliable software across the stack, from **backend systems and data pipelines to polished, user-focused web applications**.

I enjoy working on both the technical foundations of an application and the experience built on top of them — from designing APIs and data architectures to creating **clean, intuitive and visually appealing interfaces**.

My main areas of interest include:

* 🔧 Backend development & REST APIs
* ⚡ Real-time applications & event-driven architectures
* 🌐 Web applications, frontend development & UI/UX
* 🗄️ Data engineering, ETL/ELT & databases
* 🧠 AI, LLMs & RAG systems
* 🕸️ Knowledge graphs & semantic technologies
* 🤖 Automation, bots & developer tools

I'm also the founder of **[Luki-Industry](https://github.com/Luki-Industry)**, where I experiment with software, automation and community-oriented projects.
